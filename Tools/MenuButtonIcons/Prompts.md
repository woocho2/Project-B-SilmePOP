# Menu button icons

Generated with the built-in `image_gen` tool; transparent backgrounds enabled. Style reference: `Assets/4. SlimeAsset/Atlases/Sprites.png`, unchanged.

## Deliverables

- `Assets/4. SlimeAsset/UI_Icon_Quit.png`: coral power symbol for Quit Game.
- `Assets/4. SlimeAsset/UI_Icon_Settings.png`: warm-grey gear for Settings.
- `Assets/4. SlimeAsset/UI_Icon_Help.png`: sky-blue question mark for Help.

Each PNG has a single-Sprite `.meta` with transparency enabled, centered pivot, no mipmaps, bilinear filtering, clamp wrapping, and uncompressed import. The generated image pixels are preserved unchanged. Existing assets, scripts, network code, and scenes were not modified. No compile, tests, or Unity validation were run.

In Unity, assign each sprite to the desired UI Image's Source Image and enable Preserve Aspect. Scene placement and button events remain user-owned.
