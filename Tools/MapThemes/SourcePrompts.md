# Map theme artwork

Mode: built-in image_gen edit, transparent alpha. Each theme is a single 2x2 production atlas: Menu, Table, Mascot, Bar. Existing original map PNGs are exported from the corresponding sprites with dimensions and metadata preserved. Numbers remain live game text.

Original motifs were checked against the PNG backup made before the doodle conversion: Basic sprouts; Spring blossoms; Summer leaves/dew; Autumn maple leaves; Winter snowflakes; Sunny sunflower; Night moon/stars; Cloudy cloud/rain. The user also requested butterflies for Spring.
