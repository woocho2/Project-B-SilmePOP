[1] 한 줄 요약
--------------------------------------------------
같은 판, 같은 목표 합으로 최대 4명이 120초 동안 점수를 겨루는 슬라임 숫자 퍼즐 대전 게임.
방장이 빈 자리에 AI를 넣을 수 있음 (카트라이더처럼 온라인이 메인, AI는 방에서 선택).
로비/대기실/대전 중/결과 화면에서 채팅 가능.


[2] 기존 버전과 달라지는 점
--------------------------------------------------
- 기존: 사과게임과 동일한 규칙 (17x10 판, 합 10 드래그, 120초, 1인 플레이)
- 변경 1: 목표 합이 매 판 10~15 중 랜덤으로 정해짐
- 변경 2: 최대 4인 실시간 대전 (같은 시드 = 같은 판, 같은 목표 합)
          참가자는 온라인 플레이어 또는 AI
- 변경 3: 네트워크 기능 (로그인, 로비, 채팅, 방, 온라인 대전)
- 변경 4: 슬라임 종류(기본/악마/천사/킹/조커/합체)와 점수 계산
- 변경 5: 스킬 6종 (돋보기/파괴/변신/합체/조커/숫자변경)
- 변경 6: 모든 참가자(사람, AI)의 점수는 네트워크(INetworkService)를 거쳐 공유
          AI는 방장 PC에서 계산하고 방장이 대신 점수를 올림 (구현 계획서 1장)


[3] 확정 사항
--------------------------------------------------
- 대전 방식: 각자 자기 판을 푸는 점수 경쟁 (다른 사람 판에 방해하는 요소 없음)
- 인원: 방 최대 4명 (사람 + AI 합쳐서)
- AI: 방장이 빈 자리에 넣을지 선택, 자리마다 난이도 선택
- 매칭: 방 만들기만 (빠른 매칭 없음)
- 네트워크: 구현함 (과제 - 네트워크 이용, 채팅 포함 예정. 세부 필수 요구사항은 아직 미발표)
- 요구사항이 정해지지 않았으므로 기획은 특정 기술에 묶이지 않게 작성
  * 게임 코드는 INetworkService 인터페이스만 사용
  * 실제 구현(Firebase / 소켓 서버 등)은 요구사항 발표 후 선택해서 끼움
- 네트워크 1순위 후보: Firebase Realtime Database
  * 주의: Firebase Unity SDK의 Windows 지원은 beta
  * 대안: REST API(UnityWebRequest) 직접 호출
- 목표 합: 10~15, 판 시작할 때 결정, 한 판 동안 고정
- 기록: 그 판의 순위 비교용으로만 저장, 판이 끝나면 삭제 (영구 전적/최고점 없음)
- 오프라인 모드 없음: 모든 플레이는 네트워크 접속 후 방에서 진행 (과제 요구 - 네트워크 필수)
  * AI와 하고 싶으면 방을 만들고 AI를 넣어서 진행
- 맵 테마: 각자 자기가 고른 테마로 플레이 (내 화면에만 적용)
- 플랫폼: PC Windows


[4] 게임 규칙
--------------------------------------------------
- 판: 17x10, 슬라임마다 숫자 1~9
- 조작: 마우스로 사각형 드래그, 안의 숫자 합이 목표 합과 같으면 터짐
- 점수: 터뜨린 사각형 단위로 계산 ([4-2] 슬라임 종류와 점수 계산 참고)
- 시간: 120초
- 판 생성: 시드 기반 (같은 시드면 모든 참가자의 판이 완전히 같음)
- 순위: 120초 종료 시 점수 순으로 1~4위
- 동점: 그 점수에 먼저 도달한 사람이 높은 순위
  * 점수가 바뀔 때마다 "마지막 득점 시각"을 함께 기록 (경기 시작 기준 경과 시간)
- 조기 종료 없음: 120초는 항상 끝까지 진행
  * 내 판에 더 이상 만들 수 있는 수가 없으면 "더 이상 만들 수 있는 수가 없습니다!" 표시
  * 남은 스킬로 살릴 수 있으면 스킬 버튼 강조 (기존 기능 유지)
  * 막힌 뒤에는 다른 참가자 점수를 보면서 채팅 가능


[4-1] 스킬
--------------------------------------------------
- 모든 스킬은 내 판에만 작용 (다른 사람 판 방해 없음)
- 고정 구성 (로드아웃 없음), 판마다 횟수 초기화
- 섞기 스킬은 삭제
- 단축키: 1 ~ 6 (채팅 입력 중에는 비활성화)
- 사용 방식: 스킬 선택 -> 판 위에 적용 범위를 시각적으로 표시 -> 클릭으로 적용 / ESC로 취소
  * 범위 표시: 적용될 칸을 테두리+색으로 강조, 마우스를 따라 움직임
  * 범위가 판 밖으로 나가면 판 안쪽 칸만 적용 (표시도 잘린 범위로)
  * 취소하면 횟수 차감 안 함
- 스킬로 숫자가 바뀌거나 위치가 바뀌는 랜덤은 플레이어별 시드에서 파생 (리플레이/검증용)
- 변신, 합체는 위기관리용 (판이 막혔을 때 살리는 용도)
- 공통 규칙: 스킬은 기본/악마/천사/킹 슬라임에만 적용됨
  * 조커, 합체 슬라임은 어떤 스킬의 대상도 되지 않음
  * 변신(범위)은 그 슬라임만 빼고 적용 / 합체는 범위에 조커가 있으면 사용 불가

1. 돋보기 (1회)
   - 가능한 조합 1개를 표시

2. 파괴 (2회)
   - 슬라임 1개 제거, 그 슬라임의 기본점수만 획득 (특수점수는 적용 안 함)
     기본 1 / 악마 1 / 천사 2 / 킹 1

3. 변신 (1회) - 위기관리용
   - 5x5 범위 안의 슬라임마다 각각 50% 확률로 +1 또는 -1 (랜덤, 플레이어가 고르지 않음)
   - 순환: 9에서 +1 -> 1, 1에서 -1 -> 9
   - 숫자만 바뀌고 슬라임 종류(악마/천사/킹)는 그대로
   - 범위 안의 조커, 합체 슬라임은 빼고 적용

4. 합체 (1회) - 위기관리용
   - 2x2 범위의 슬라임을 하나로 합침
   - 합쳐진 슬라임의 숫자 = 모든 숫자 합의 일의 자리
     예) 3+4+5+6 = 18 -> 8
   - 일의 자리가 0이면 그 자리에서 바로 파괴 -> "합체된 슬라임 수 x4" 점 획득
     예) 2+3+7+8 = 20 -> 파괴, 4마리 x4 = 16점
   - 합쳐진 슬라임은 2x2 네 칸을 모두 차지하는 큰 슬라임
     * 네 칸의 콜라이더는 그대로 남고, 각 콜라이더가 같은 합체 슬라임을 가리킴
     * 드래그 범위에 네 칸 중 한 칸만 걸쳐도 합체 슬라임이 포함됨
     * 합 계산에는 1번만 들어감 (중복 제거)
   - 2x2 범위에 조커가 있으면 그 위치에는 합체 사용 불가 (범위 표시를 빨간색으로)
   - 2x2 안에 빈칸이 있어도 슬라임이 2마리 이상이면 사용 가능, 합체 후 항상 4칸 차지
   - 합체 결과는 "합체 슬라임"이라는 별도 종류, 전용 스프라이트 사용
     (악마/천사/킹이 섞여 있어도 결과는 합체 슬라임)
   - 합체 슬라임의 기본점수 = 합쳐진 슬라임들의 기본점수 합, 특수점수 없음
     예) 기본+기본+악마+천사 합체 -> 기본점수 1+1+1+2 = 5, 특수점수 없음

5. 조커 (1회)
   - 기본 슬라임에만 사용 가능 (악마/천사/킹에는 불가)
   - 효과: 그 슬라임이 조커 슬라임이 됨 (기본점수 3, 특수점수 +(목표 합 x2), [4-2] 참고)
   - 5초마다 랜덤한 빈자리로 이동 (다른 슬라임과 자리를 바꾸지 않음)
     * 빈자리가 없으면 움직이지 않음
     * 합체 슬라임이 차지한 칸은 빈자리가 아님
   - 드래그 중이어도 시간이 되면 그대로 이동 (따라잡는 것도 실력)
   - 조커 위에 다음 이동까지 남은 시간 표시

6. 숫자변경 (3회)
   - 슬라임 1개의 숫자를 1~9 중 랜덤으로 변경 (원래 숫자는 제외)
   - 숫자만 바뀌고 슬라임 종류는 그대로


[4-2] 슬라임 종류와 점수 계산
--------------------------------------------------
종류 (모두 숫자 1~9를 가짐) - 슬라임마다 "기본점수"와 "특수점수"가 있음
                기본점수                        특수점수
  기본 슬라임 :   1                             +0
  악마 슬라임 :   1                             x(-1)
  천사 슬라임 :   2                             x2
  킹 슬라임   :   1                             +10
  조커 슬라임 :   3                             +(목표 합 x2)  예) 목표 10 -> +20 / 목표 15 -> +30
  합체 슬라임 :   합쳐진 슬라임들의 기본점수 합  없음
  * 조커는 조커 스킬로 기본 슬라임을 바꿔서 만듦 ([4-1] 5번)
  * 합체 슬라임은 합체 스킬로 만듦, 2x2 네 칸 차지 ([4-1] 4번)

계산 (사각형 하나를 터뜨릴 때, 전부 더하기)
  B = 사각형 안 슬라임들의 기본점수 합
  최종 점수 = B
            + 곱하기 특수점수(천사/악마)는 마리마다 B x 배수 를 더함
            + 더하기 특수점수(킹/조커)는 마리마다 그 값을 더함
  * 조커의 x2는 고정 (슬라임 수와 무관)
  * 점수가 마이너스가 될 수 있음 (총점도 마이너스 가능)

예시 (확정)
  천사 + 악마 : B = 2+1 = 3  ->  3 + 3x2 + 3x(-1) = 6
  천사 + 킹   : B = 2+1 = 3  ->  3 + 3x2 + 10     = 19

예시 (위 규칙 적용)
  기본 + 기본 : B = 2  ->  2
  기본 + 악마 : B = 2  ->  2 - 2           = 0
  기본 + 천사 : B = 3  ->  3 + 6           = 9
  기본 + 킹   : B = 2  ->  2 + 10          = 12
  악마 + 악마 : B = 2  ->  2 - 2 - 2       = -2
  천사 + 천사 : B = 4  ->  4 + 8 + 8       = 20
  킹 + 킹     : B = 2  ->  2 + 10 + 10     = 22

조커 예시 (목표 합 10 기준)
  기본 + 조커        : B = 4  ->  4 + 20            = 24  (확정)
  기본 + 기본 + 조커 : B = 5  ->  5 + 20            = 25  (확정)
  천사 + 조커        : B = 5  ->  5 + 5x2 + 20      = 35
  악마 + 조커        : B = 4  ->  4 - 4 + 20        = 20
  킹 + 조커          : B = 4  ->  4 + 10 + 20       = 34

판마다 출현 수 (17x10 = 170마리 중)
  킹 2 / 천사 3 / 악마 5 / 나머지 160 기본
  * 위치와 숫자는 시드로 정함 -> 모든 참가자가 완전히 같은 배치
  * 조커, 합체 슬라임은 판 생성 시 없음 (스킬로만 생김)

외형
  - 악마/천사/킹/조커/합체 슬라임은 각각 전용 에셋(그림)으로 새로 제작
    (기본 슬라임에 코스튬을 덧씌우는 방식이 아님)
  - 판 생성 시 슬라임 종류에 맞는 에셋으로 생성
  - 코스튬 꾸미기 기능 제거 -> 메뉴/옵션의 코스튬 선택 버튼 제거
  - 얼굴 꾸미기 기능 제거 (얼굴 없음으로 통일)
  - 기본 슬라임 색: 색깔마다 자세가 다른 전용 에셋 8개를 제작
    (기존처럼 흰 슬라임에 색을 입히는 방식이 아님)
    * 플레이어가 8개 중 하나를 선택 (기존 색 버튼 8개 자리: 흰/검/빨/파/노/초/연두/갈)
    * 커스텀 색(컬러피커) 제거
  - 특수 슬라임(악마/천사/킹/조커/합체)은 고정 외형 (색 선택 영향 없음)


[5] AI 참가자
--------------------------------------------------
- 방장이 대기실의 빈 자리에 AI를 넣음, 자리마다 난이도 선택 (최대 3명)
- AI 계산은 방장 PC에서 하고, 점수만 서버에 올림
- 상대가 AI라는 것을 화면에 명확히 표시 (이름 옆 AI 표시 등)

동작
  1. 현재 판에서 합이 목표 합인 사각형을 모두 찾음 (기존 누적합 탐색 재활용)
  2. 난이도에 따라 하나 선택
  3. 생각 시간만큼 기다린 후 터뜨림

난이도
                  반응 시간(랜덤)   정답확률
  쉬움          : 2 ~ 5초           50%
  보통          : 1 ~ 4초           70%
  어려움        : 0.75 ~ 2초        90%
  게임판 확인용 : 0.5 ~ 1초         100%   (테스트/밸런스 확인용)

정답확률 = "최선의 수"를 고를 확률
  - 매 턴 가능한 사각형을 모두 찾고, 각 사각형을 평가해서 가장 좋은 수를 계산
  - 정답확률만큼은 최선의 수를 고르고, 나머지 경우는 가능한 사각형 중 랜덤 선택
  - AI는 실패 드래그(합이 틀린 드래그)를 하지 않음 - 확정
    (AI는 반응 시간이 핸디캡. 사람은 실수할 수 있지만 몇 수 앞을 기억해두면 1초에 3~4개도 가능)
  - 최선의 수 평가 로직 (안)
    1) 지금 얻는 점수 ([4-2] 계산 - 악마가 들어간 사각형은 손해, 킹/천사/조커는 우선)
    2) 지우고 난 뒤 판에 남는 가능한 사각형 수 (다음 수가 막히지 않게)
    3) 지우고 난 뒤 다음 턴에 얻을 수 있는 최고 점수 (한 수 앞 보기)
    -> 세 값을 가중치로 합산해서 가장 높은 사각형 선택 (가중치는 시뮬레이션으로 조정)
  - 스킬 사용 (안): 쉬움은 안 씀 / 보통은 막히면 숫자변경, 파괴 / 어려움 이상은 상황 판단

AI 시뮬레이션 (개발/밸런스용)
  - AI끼리 대전시켜서 결과를 빠르게 확인 (반응 시간 없이 BoardModel만으로 수천 판 돌리기)
  - 확인할 것
    * 목표 합 10~15별로 판이 막히는 시점, 평균 점수
    * 난이도별 평균 점수 차이 (쉬움 < 보통 < 어려움이 확실히 나오는지)
    * 특수 슬라임/스킬 점수 밸런스 (조커, 킹이 너무 센지 등)
  - 결과는 로그/CSV로 출력

사람처럼 보이게 하기
  - 반응 시간에 랜덤 편차
  - 사각형이 클수록 오래 걸림
  - 가끔 연속으로 빠르게 터뜨리는 구간


[6] 네트워크 기능 (안)
--------------------------------------------------
로그인
  - 게스트 로그인만 (아이디/비밀번호 없음): 닉네임만 입력하면 바로 접속
    * 내부적으로는 Firebase 익명 로그인 -> 접속할 때마다 임시 uid를 받음
    * 영구 기록이 없으므로 게임을 껐다 켜면 새 게스트로 접속해도 문제없음
    * 닉네임은 다음 접속 때 편하게 PC에 저장해 두고 입력칸에 미리 채움 (PlayerPrefs)
    * 같은 닉네임 허용 - 확정. 화면에는 "닉네임#1234"처럼 4자리 태그를 붙여 구분
      (태그는 uid에서 만듦 -> 서버에 따로 확인할 필요 없음)

로비
  - 접속 중인 유저 목록
  - 전체 채팅 (로비 채팅)
  - 방 목록 / 방 만들기 (빠른 매칭 없음)

대기실 (방)
  - 최대 4자리, 방 채팅
  - 방장이 빈 자리에 AI 추가/제거, 자리마다 난이도 선택
  - 사람은 준비 버튼, AI는 항상 준비 상태
  - 모두 준비하면 방장이 시작
  - 방장이 시드, 목표 합을 정해서 방에 기록

방장 퇴장
  - 대기실에서 나감
    * 다른 사람이 있으면 -> 남은 사람 중 랜덤 1명에게 방장을 넘김 (AI 계산도 새 방장 PC로 이동)
    * AI만 남으면 -> 바로 방 삭제
  - 대전 도중 나감 -> 그 판이 끝날 때까지 그대로 진행
    * 나간 방장은 기권 처리 (최하위)
    * AI는 방장 PC에서 돌고 있었으므로 그 순간 점수로 멈춤 (순위에는 포함)
    * 판이 끝나면: 다른 사람이 있으면 랜덤 1명에게 방장을 넘김
                   AI만 남았으면 결과 처리 후 바로 방 삭제

온라인 대전
  - 시작 시각(서버 시간 기준)에 맞춰 동시에 카운트다운
  - 점수가 바뀔 때마다 서버에 올리고, 다른 참가자 점수는 실시간으로 받음
  - 대전 중 채팅: 일반 텍스트 채팅
    * Enter로 입력창 열기 / 전송 후 닫기
    * 입력창이 열려 있는 동안 스킬 단축키(1~6) 비활성화 (타이핑과 충돌 방지)
    * 채팅창은 판을 가리지 않는 위치에 반투명으로
  - 참가자 연결 끊김 -> 그 참가자는 기권 (최하위), 나머지는 계속 진행
  - 경기 종료 시 각자 최종 판 상태를 서버에 올림 (결과 화면에서 보여주기 위함)

결과 화면
  - 1~4위 순위, 점수
  - 각 참가자의 최종 판을 보여줌 (대전 중에는 다른 사람 판을 보여주지 않음)
    * 그 참가자가 고른 슬라임 색/맵 테마로 보여줌 (최종 판과 함께 색/테마 정보도 전송)
  - 방 채팅 유지 (GG 등)
  - 재대결 / 로비로
  - 대기실로 돌아가거나 방이 끝나면 그 판 기록 삭제

데이터 구조 예시 (Realtime Database)
  users/{uid}            : 닉네임, 접속 여부
  lobbyChat/{msgId}      : uid, 닉네임, 내용, 시간
  rooms/{roomId}
    hostUid, seed, targetSum, startAt, state(대기/진행/결과)
    slots/{0~3}          : 사람(uid) 또는 AI(난이도), 닉네임, ready
    scores/{slot}        : score, lastScoreTime, connected
    finalBoards/{slot}   : 경기 종료 시 최종 판 상태 (170칸), 슬라임 색, 맵 테마
    chat/{msgId}         : uid, 닉네임, 내용, 시간
  * scores, finalBoards는 판이 끝나면 삭제

신경 쓸 것
  - 시간 동기화 (각 PC 시계가 다름 -> 서버 시간 기준으로 시작)
  - 연결 끊김 처리 (onDisconnect 또는 하트비트)
  - 채팅 도배/길이 제한
  - 점수 조작 방지 (최소한 보안 규칙: 1회 변화량 상한. 점수가 마이너스도 되므로 "증가만" 규칙은 불가)


[7] 화면 흐름
--------------------------------------------------
시작 화면 -> 메인 메뉴
 -> 로그인(닉네임) -> 로비(채팅)
 -> 방 만들기 / 방 입장 -> 대기실(채팅, AI 추가, 준비)
 -> 목표 합 공개 연출 (숫자 룰렛처럼 돌다가 멈춤)
 -> 카운트다운 3, 2, 1
 -> 플레이 120초
 -> 결과 화면 (순위, 점수, 각자 최종 판, 채팅)
 -> 재대결(대기실) / 로비로

플레이 화면 배치 (안)
  - 가운데: 내 판 (크게)
  - 옆: 참가자 점수판 (실시간 순위, AI 표시)
  - 상단: 남은 시간, 목표 합
  - 하단 또는 옆: 채팅창 (반투명)
  - 스킬 버튼 6개 + 남은 횟수 + 단축키 표시
  - 다른 참가자의 판(미니맵)은 표시하지 않음
  - 대전 중에는 일시정지 없음, 홈 버튼은 "기권"으로 변경
